The current leaderboard ranks league membership records. Two membership records for the same learner profile therefore produced two rows, repeated the same lifetime XP, and inflated other learners' ranks. The schema permits these records; a runtime race is a possible source, not an observed live cause. The small fix selects one membership per learner_profile_id within the requested league before computing and ranking XP, using the oldest membership as the representative. It does not sum duplicate memberships, delete records, merge profiles, collapse matching names, or change XP awards/weekly ranking rules. Both the board and Your spot use the same corrected ranked collection.

This is a reproduced code-path fix, not a verified diagnosis of live Lucy. The workbook supplies her display name and total XP but not learner or membership IDs. If the live two Lucy rows have different learner IDs, both remain visible and need a separate ownership review. Names and equal XP are not safe merge keys. Read-only local inventory found no duplicate league/profile membership groups, so no local database cleanup or synthetic membership insertion was performed.
