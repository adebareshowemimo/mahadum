## Result

Each correct question earns 1 XP in each permitted quiz attempt, including deliberate retries. The audit example now awards +4 XP for 4/10 correct (40%), then +2 for 2/10 on Retry (20%): quiz XP totals 6. Wrong answers earn zero. Within one attempt, a question earns at most once, including wrong-to-correct submissions. Current max_attempts, hearts cadence/12-hour lock, paid unlimited hearts, lesson access and one-time non-quiz lesson bonus remain unchanged. No historical XP is backfilled or deleted; old attempts and ledgers are preserved.

The API previously opened a fresh attempt after the final answer, making a resent final transport indistinguishable from a deliberate Retry. Each submission now requires request_id (string, maximum 128 characters). The live player retains the ID on a lost-response retry, renews the quiz IDs on explicit Retry/Review lesson video/Start over, and distinguishes changed answers. A durable per-learner receipt, saved inside the existing learner-locked answer transaction, returns the original result for the same request. Its original xp_awarded value describes the original award; it is not a second award. Reusing the ID with changed content returns 409. Missing ID returns 422. Learner authorization and current access/hearts checks still run before replay; receipts cannot unlock exhausted hearts or another family's learner. Receipt replay also works after cache flush and 25 hours.
