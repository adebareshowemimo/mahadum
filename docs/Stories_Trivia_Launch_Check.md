# Stories and trivia launch check

The 28 October requirement is recorded in the BRD and content model. Deploy the code and run migrations and the roles and permissions seeder so school admins can open the story and set catalogues read only.

The five story bands are Ages 0–5, Ages 6–12, Ages 13–17, Adults 18+, and Folklore. Each accepts a video, text, or quiz item. Proverb and Trivia sets accept learner-facing text, video, and quiz components. The existing course quiz editor is used for set questions. Story quizzes have server-held answers and a one-question free preview.

Before launch, obtain culturally and linguistically reviewed content and publish at least one item in each of the seven columns. For each column, check its video, text, and quiz choices in a creator account, then view the published item with a learner profile. Check the free preview and paid access of stories, including a second quiz question staying locked until a confirmed purchase. Verify that a school admin can open the catalogue and preview but cannot create or publish content. Record the item IDs, reviewers, and test results. Do not publish sample or invented cultural content as launch material.
